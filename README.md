# 組立前の部品準備を数理最適化で解く ― サンプルコード

書籍『組立前の部品準備を数理最適化で解く ― 外段取り化とトレイ配置で学ぶ、製造現場の数理モデル入門』（梅田耕嗣、合同会社DeUX）のサンプルコードです。

組立に使う部品を標準の部品箱に入れ、カートのトレイ（1200 × 600 mm）に並べる問題を、次の2段階で解きます。

1. **部品箱の寸法を決める**（第4章）：寸法の候補から K 種類を選ぶ「品揃え問題」を混合整数計画（MILP、PuLP＋CBC）で解く
2. **部品箱をトレイに並べる**（第5章）：トレイ枚数を最小にし、作業順に並ぶように配置する（OR-Tools CP-SAT）

データはすべて乱数で作った架空のものです。実在の企業・部品・BOMとは関係ありません。

## 動かし方

Python 3.10〜3.13 で動作を確認しています。

```bash
git clone https://github.com/kojiumeda-prog/book-kitting.git
cd book-kitting
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python scripts/run_all.py --quick  # 動作確認（数分）
python scripts/run_all.py          # 本の数値と図をすべて作り直す（30〜40分）
python -m pytest -q                # テスト
```

Google Colab でも、最初のセルで `!pip install ortools==9.15.6755 pulp==2.9.0` を実行すれば動きます。

## 再現性について

- データ生成と第4章のMILP（CBC、1スレッド）は、何度実行しても同じ結果になります。
- 第5章の作業順の最適化は、工程を数個ずつ1スレッドで解き直す方法（大近傍探索、LNS）で行い、計算時間を「決定的時間」で区切っています。同じ版のOR-Toolsなら、何度実行しても同じ配置になります。
- CP-SATを複数スレッドで一度に解く `solve_sequence` も入れてあります。速いですが、並列探索のため実行ごとに解が少し変わります。
- OR-Toolsの版が違うと結果が変わることがあります。`requirements.txt` の版を使ってください。

## 結果の概要

`python scripts/run_all.py` の実行結果です。

### 第4章：部品箱寸法（10種類の事前組立品、部品計589点）

| 寸法の決め方 | 採用した部品箱（外形mm） | 全BOMの合計面積 | 共通トレイの面積 | どの部品箱にも入らない大物 |
| --- | --- | --- | --- | --- |
| 論文の4種類＋2008年の割当ルール | 75x75, 150x150, 300x150, 300x300 | 2,245 ブロック | 506 ブロック | 21点 |
| MILPで4種類を選ぶ（共通トレイの面積を最小化） | 75x75, 150x150, 300x225, 600x75 | 2,234 ブロック | 418 ブロック（−17%） | 0点 |

種類数 K を 2〜8 に変えた結果は `results/ch4_sizing.csv` と `figures/fig4-6_k_vs_area.png` にあります。CBCで各数秒、すべて最適解です。

### 第5章：トレイ配置（SA-10：39工程、部品106点、部品箱126個、面積406ブロック）

第4章で選んだ4種類の部品箱に、各部品を必要面積が最小になるように入れたものを使います（`bins.assign_cheapest`）。

| 配置方法 | トレイ枚数 | トレイをまたぐ工程 | 工程の散らばり | 順序一致率 | トレイ間の移動 | 罰則 | 計算時間 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ① サイズ順ルール | 4 | 20 / 31 | 14.5 | 62% | 45回 | — | 0.01秒 |
| ② 枚数のみ最適化（CP-SAT） | 4 | 25 / 31 | 18.4 | 57% | 62回 | — | 8秒 |
| ③ 作業順ルール | 4 | 1 / 31 | 9.9 | 99.8% | 3回 | 1,944 | 0.01秒 |
| ④ 作業順の最適化（LNS） | 4 | 1 / 31 | 8.1 | 98% | 3回 | 1,594（−18%） | 約4分 |

部品を使う工程は39工程のうち31工程です。トレイ4枚は面積の下界（406 ÷ 128 の切り上げ）と同じで、最小です。

### 第5章 5.8節：問題の大きさと計算時間（LNS 2周、`results/scale_test.csv`）

部品箱20〜126個の10種類すべてで、作業順ルールに比べて罰則が10〜37%減りました。計算時間は5〜117秒です。
